## Lich 5 capability inventory (elanthia-online/lich-5, v5.21.0, Ruby 3.2+)

Scope per README: an open-source Ruby **scripting engine / proxy server** for Simutronics' DragonRealms and GemStone IV. Not a front-end itself — it sits between the user's chosen FE and the game server, "expanding the front-end's features." Recent CHANGELOG direction (5.19→5.21): concurrent runtime I/O + multi-client detach, a 6-part script-lifecycle hardening series (supervised child scripts, synchronized transitions, shutdown draining, forced teardown), map lookup rework (legacy mapdb formats dropped, JSON only), GUI launcher + configurable frontend registry, HTTPS web-login fallback when EAccess:7910 is unreachable, GemStone combat module + creature template library, and lots of DR inventory/GameObj reconciliation.

### 1. Core architecture
Entry: `lich.rbw` (6.5KB) → `lib/init.rb` (593) requires everything → `lib/main/main.rb` (1155, "needs work to break up"). Flow: arg parse (`lib/main/argv_options.rb`, `arg_normalization.rb`, `lib/common/arg_parser.rb`, `cli/cli_options_registry.rb`) → auth → open a `ReusableTCPServer` listener → launch the FE (`frontend_launcher.rb`, `process_launcher.rb`, hosts-file/SAL redirection) → accept the FE as `$_CLIENT_` → `Game.open` to the real server → two pump threads.
- **Auth**: `lib/common/authentication/` — `eaccess.rb` (SGE protocol on :7910), `web_login.rb` (HTTPS fallback), `authenticator.rb`, `entry_store.rb` (1131, encrypted saved logins), `cli.rb`/`gui.rb`, `launch_data.rb`/`launch_result.rb`, `login_helpers.rb`. Credentials scrubbed post-login (`credential_scrub.rb`) because ARGV/ivars are reachable from script bindings.
- **Transports**: `SynchronizedSocket` wrapper, `socketconfigurator.rb`, `socket_read_hook.rb`, `bind_host_resolver.rb`, `--pipe` mode via `pipe_io.rb` (stdin/stdout as client, EOF = client dead), `sharedbuffer.rb`/`buffer.rb` for stream fan-out.
- **Detachable clients**: `detachable_client_registry.rb` + ~15 `detachable_*` globals in global_defs (register/unregister/respond/close/send_init/send_player_id, primary-client election), per-game `*/detachable_client_init.rb`.
- **Frontends (9)**: `lib/common/frontend/` — wrayth, wizard, genie, profanity, avalon, frostbite, saga, suks + a registry (`frontend.rb`, 928) with capability vocabulary (`supports_xml?/gsl?/streams?/mono?/room_window?`), user-overridable definitions, `frontend_locator.rb`, `frontend_settings.rb`, Win32 PID/window-focus FFI via Fiddle. Saga gets a dedicated managed-launch path (`saga_launch_policy.rb`, `saga_managed_launcher.rb`, `saga_managed_login.rb`).
- **Lifecycle**: `session_launcher.rb`, `session_lifecycle.rb`, `gameloader.rb`, plus an unusually elaborate shutdown subsystem — `shutdown_coordinator.rb`, `shutdown_intent.rb`, `shutdown_watchdog.rb`, `shutdown_script_drain.rb`, `shutdown_log.rb`, `orderly_shutdown.rb`, `best_effort_shutdown_cleanup.rb`. Multi-session coordination via `lib/api/active_sessions.rb` + `lib/internal_api/active_sessions/`.
- `lib/games.rb` (1677) is the game-socket/protocol layer; `lib/lich.rb` (1265) holds global config, sqlite handle, msgbox, logging.

### 2. Scripting runtime — `lib/common/script.rb` (3675, the largest hand-written file)
Each script is a **Ruby Thread** (plus a ThreadGroup of worker threads) executing the script file's text via `eval(source, script_binding, script.name)`. Two binding flavors: `TRUSTED_SCRIPT_BINDING = proc { _script }` and untrusted `Scripting.new.script` — both are `Proc.new {}.binding`. A leading comment warns the bindings are "convoluted" and that changing them leaks local variables between scripts or makes `Script.start` callable unqualified. Untrusted scripts run label-by-label in a loop; `goto`/labels are implemented by re-eval'ing the next label chunk and a `JumpError` exception.
Subclasses: `SubScript` (block-based), `ExecScript` (`;e <ruby>` — evals a string), `WizardScript` (translates Wizard FE `.cmd` macro syntax).
API: `Script.start/run/exists?/running?/pause/unpause/kill/kill_all/paused?/list/log/db/open_file/at_exit/exit!/current/self/index/hidden/trust/distrust/list_trusted`, plus new supervised-child APIs `start_child`, `run_child(timeout:, execution_guard:)`, `subscript`, `daemon_me`, `join/kill_sync`, library loading `loadlib/reloadlibs/libs` with dependency-cycle detection and timeouts, and `Script.version` / `required_lich_version` / `require_lich_version!` header-comment parsing. Explicit lock ordering documented (startup → registry → lifecycle → child relationship). Kill metrics instrumentation included.
`script_execution_guard.rb` (152) — cooperative cancellation: guards expose `checkpoint!(command:)` called at every blocking/mutating point (5.21 "enforce Script#pause at every blocking/mutating checkpoint"), `cancel!`, `close!`, `check_script_start!` to forbid a guarded worker from starting scripts; raises `ScriptExecutionGuard::Interrupted`. Docs: `docs/script-execution-guard.md`.
`hmr.rb` (38) — hot module reload: greps `$LOADED_FEATURES` against a regex and `load`s matches. `script_death.rb` for die_with/before_dying. Dependency recovery: `lib/bundler_recovery.rb` (365, macOS-focused, see `docs/macos-bundler-recovery.md`), `lib/dependency_recovery.rb` (784, restores sqlite3/gtk3 from an approved manifest, may signal restart_required), `lib/gemcheck.rb` (575, verifies Bundler-group gems, stderr + bounded GTK dialog).

### 7. Ruby-specific tricks (hard to port)
- **`eval` of script source against hand-crafted `Proc.new {}.binding` objects** is the whole execution model; label jumps re-`eval` fragments and rely on `$1..$n` globals surviving (`global_defs.rb:1682` does `eval("$#{n+1}")`).
- `StringProc` — a fake Proc that stores Ruby source, lies about `class`/`kind_of?`, `eval`s on `call`, and Marshal-dumps as source. Used pervasively for map waytos and spell data, so **map/spell data files contain executable Ruby**.
- `Spell` evals formula strings for duration/bonus/cast procs and uses `method_missing` for bonus lookup.
- `method_missing` as the primary API for `Vars`, `UserVars`, `SessionVars`, `Settings`/`SettingsProxy`, `Games`, wounds/scars; `define_method` to generate per-body-part wound accessors and proxy operators.
- Monkeypatching core classes: `lib/common/class_exts/` on String, Hash, Numeric, NilClass, MatchData; `lib/deprecated.rb` aliases old global names with caller reporting; `lib/common/user_defs.rb` lets users inject defs.
- `Script#instance_variable_get`/`instance_eval` are deliberately stubbed to return `nil` (sandbox hardening).
- `ThreadGroup` internals captured as unbound methods (`ThreadGroup.instance_method(:add)`) and re-dispatched to defeat scripts that reopen ThreadGroup; a `ThreadGroupHandle` module patches ThreadGroup globally.
- `Frontend.load_built_in_catalog!` uses `module_eval(File.read(path))` to load FE definitions.
- `Marshal` round-tripping of arbitrary objects into sqlite BLOBs (settings/vars).
- `WeakRef`, `ObjectSpace`, manual GC/compaction, `Thread#raise`-based kills, `exec()` self-re-launch for reconnect, Fiddle FFI for Win32.
